Panduan Penggunaan

Pelajari cara memaksimalkan fitur Sinkronisasi aplikasi Minat Pintar.

1. Melakukan Pengaturan Awal (Wajib)

Sebelum mengunduh laporan atau menyebarkan link, atur identitas sekolah terlebih dahulu untuk tanda tangan di laporan Excel dan PDF.

  • Pilih menu Pengaturan Dokumen di sidebar sebelah kiri.
  • Masukkan Tempat Ditetapkan, Nama & NIP Kepala Sekolah.

2. Membagikan Tautan (Link) Tes ke Siswa

Siswa tidak perlu mengakses dashboard. Mereka hanya membuka link tes yang spesifik. (Catatan: Untuk dapat membagikan link ke HP siswa di rumah, file aplikasi HTML ini perlu di-upload ke layanan Hosting/Cpanel sekolah terlebih dahulu).

  • Buka menu Daftar Link Tes.
  • Klik tombol Salin Link pada jenis tes yang diinginkan.
  • Kirim link tersebut ke Grup WhatsApp siswa.

3. Sinkronisasi Data Cepat (Tombol Refresh)

Anda tidak perlu merefresh seluruh browser yang bisa membuat Anda logout. Cukup klik tombol Refresh Data di bagian kanan atas atau di dalam menu. Sistem akan otomatis menarik seluruh data jawaban siswa ke dalam memori aplikasi Anda.
